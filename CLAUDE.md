# hack-14

A single Next.js 16 app (App Router, Turbopack). Google sign-in only — no
database. See `readme.md` for setup and the OAuth design.

## This is NOT the Next.js you know

Next 16 has breaking changes — APIs, conventions, and file structure may all
differ from your training data. Read the relevant guide in
`node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.

Specifically:

- `cookies()` from `next/headers` is **async** — always `await` it.
- `cookies().set()` / `.delete()` only work inside route handlers and server
  actions, not in server components.
- `next dev` regenerates `AGENTS.md` at the repo root. It's gitignored; don't
  commit it, and don't move its content here by hand.

## Layout

```
app/
  page.tsx                     sign in / sign out UI (client component)
  lib/types.ts                 the User type
  lib/env.ts                   env vars, read lazily
  lib/session.ts               session + OAuth-transaction cookies
  lib/google.ts                authorization URL, PKCE, code exchange, ID-token verification
  api/auth/{login,callback/google,me,logout}/route.ts
```

## Conventions

- Env vars are read through **getter functions** in `app/lib/env.ts`, never at
  module scope. `next build` evaluates route modules, so a missing variable must
  break a *request*, not the build.
- `app/lib/{env,session,google}.ts` are server-only (`import "server-only"`).
  Never import them from a client component.
- Routes are same-origin, so client fetches need no `credentials: "include"`
  and there is no CORS config.
- The session cookie is **signed, not encrypted**. Its payload is readable
  base64 — never put anything sensitive in it.
- Avoid `next/font/google`: it fetches at build time, which fails in restricted
  network environments. The app uses a system font stack.

## Checks before calling anything done

```bash
npx tsc --noEmit
npx eslint .
npm run build
```

If npm fails with an `EPERM … _cacache` "root-owned files" error, the cache
path isn't writable — prefix the command with
`npm_config_cache="$TMPDIR/npm-cache"`.

## Secrets

Real credentials live only in `.env.local`, which is gitignored. Never read,
print, or commit it. `.env.example` carries placeholders only. `SESSION_SECRET`
is generated by the user (`openssl rand -hex 32`).
